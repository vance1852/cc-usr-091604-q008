# 样本监管链服务

赛事反兴奋剂样本监管链（Chain of Custody）服务：登记运动员身份、采样批次、
容器封条、采样时间、冷藏温度与当前保管人，采样官 → 运输人员 → 实验室逐环
交接，合规主管负责异常处置授权与审计。纯 Python 标准库实现，无外部依赖。

## 架构

事件溯源（event sourcing）：所有业务事实只以**事件**形式写入一条仅追加的
哈希链日志（JSONL + SHA-256 前向链），当前状态完全由重放得到，原始记录
永不修改。异常只能追加"申报/隔离/处置"事件，不能改写历史。

```
app/
├── models.py       角色/状态/异常枚举、值对象、HMAC 签名、PII 脱敏
├── eventstore.py   append-only 哈希链事件日志（fsync 落盘、启动校验）
├── state.py        事件重放投影（样本状态、A/B 父子关系、授权单、幂等表）
├── service.py      核心领域服务：登记/扫描/交接/隔离/拆分/复检/销毁/查询/审计
├── api.py          零依赖 HTTP 接口（http.server）
└── samples.py      向后兼容入口（Sample / CustodyService 再导出）
```

### 交接校验顺序（任一不过即拒绝，且不落任何事件）

1. 身份凭据与角色；2. 必须是当前保管人发起；3. 样本未隔离、非终态；
4. 只允许 采样官 → 运输 → 实验室（越级/反向即越权）；
5. 时间窗（采集起 2h 内交运输、单段不超 48h、总时长 72h，UTC 绝对时刻比较，
   naive 时间戳直接拒绝）；
6. 前一环 HMAC-SHA256 签名（绑定 条码/时刻/交出人/接收人，用常量时间比较）；
7. 封条编号必须与登记完全一致——不一致或被调换直接拒绝，需走异常+授权换封；
8. 送达实验室时强制冷链：2–12 ℃ 且读数间隔 ≤ 3h（开头/中间断档均拒绝）。

### 异常与隔离

任何链上角色可申报异常（封条不符/破损、超温、文书不符、容器破损）；
申报后样本及其 A/B 瓶**全家自动隔离**，正常流程全部冻结。只有合规主管
能记录处置结论后解除隔离；换封条只允许在隔离中凭一次性授权单+另一人见证
完成，新旧封条永久留痕在 `seal_history`。

### A/B 瓶、复检与销毁

实验室在库拆分出 `{条码}-A`（检测）与 `{条码}-B`（复检留存），保持父子
关系；复检只能对 B 瓶，复检/销毁都必须出示合规主管签发的一次性授权单
（校验对象、用途、有效期、是否已核销），全部事件入审计轨迹。

### 可靠性

* **断网重试**：写命令支持幂等键；交接的幂等检查在保管人校验之前，
  首次请求若已成功（保管人已前移），重试回放首次结果而非误判越权。
* **重复扫描**：同一条码同一扫描令牌直接返回既有记录；携带不同数据
  （如换了封条号）则拒绝，不能借重复扫描覆盖原始登记。
* **跨时区**：入口时间一律带时区并归一化为 UTC，用不同时区表示同一
  绝对时刻的签名与时间窗都能通过（有测试）。
* **重启可回放**：启动从 JSONL 重建状态并校验整条哈希链；篡改任何一个
  历史字段都会在加载时抛 `IntegrityError`（有测试）。

### 隐私

运动员姓名/证件号仅合规主管可见明文；其他角色查询时自动脱敏
（姓 + `*`、证件号只留尾号）。审计导出仅合规主管可用。

## 运行

```bash
python3 -m unittest discover -s tests -v   # 41 个测试
python3 -m app.api /tmp/custody.jsonl      # HTTP 服务，默认 127.0.0.1:8080
```

## HTTP 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/users` | 注册角色用户（演示引导） |
| POST | `/samples/scan` | 扫描录入（同条码重复扫描幂等） |
| POST | `/samples` | 登记样本 |
| POST | `/samples/{bc}/temperatures` | 补录冷藏温度（当前保管人） |
| POST | `/samples/{bc}/handover` | 逐环交接 |
| POST | `/batch-handovers` | 批量交接（单项失败不牵连） |
| POST | `/samples/{bc}/anomalies` | 异常申报（自动隔离全家） |
| POST | `/samples/{bc}/release` | 合规主管解除隔离 |
| POST | `/samples/{bc}/seal` | 隔离中授权换封条（双人见证） |
| POST | `/samples/{bc}/split` | 拆分 A/B 瓶 |
| POST | `/authorizations` | 签发授权（retest/destroy/seal_replace/release） |
| POST | `/samples/{bc}/retest` | 授权复检（仅 B 瓶） |
| POST | `/samples/{bc}/destroy` | 授权销毁 |
| GET  | `/samples/{bc}` | 状态查询（按角色脱敏） |
| GET  | `/batches/{batch}` | 批次列表 |
| GET  | `/audit?barcode=` | 审计导出（仅合规主管，导出前校验哈希链） |

身份通过 `X-Actor-Id` / `X-Actor-Role` 头与密钥（`X-Actor-Key` 或
POST 体内 `key`）表示；交接签名使用各方 HMAC 密钥，待签名文本为
`HANDOVER|条码|UTC时刻|交出人|接收人`。

## 测试覆盖

`tests/test_custody.py`（39 个）与 `tests/test_api.py`（2 个）覆盖：
正常全流程、**拒绝越权交接**（非保管人、越级、反向、伪造签名、
签名绑定字段）、**拒绝非法封条替换**、时间窗与时间倒退、冷链缺失/
超温/断档、异常隔离与解冻、授权一次性/过期/用途对象不符、脱敏、
幂等重试与冲突、重复扫描、跨时区、批量部分成功、重启重放与篡改检测。
